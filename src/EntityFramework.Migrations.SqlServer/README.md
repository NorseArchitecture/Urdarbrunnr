# Norse.EntityFramework.Migrations.SqlServer

Pulls in `Norse.EntityFramework.Migrations` (contributor base) and `Norse.EntityFramework.SqlServer` (Aspire SQL Server wiring) and ships the Roslyn generator that emits `AddNorseMigrations()`. Reference this single package from your migrations service.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
